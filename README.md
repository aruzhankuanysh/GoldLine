# GoldLine — React интерфейс ломбарда

Демо-панель на React + Vite в желто-черно-белой стилистике.

## Запуск
1. Установить Node.js 18+.
2. В папке проекта выполнить:
   npm install
   npm run dev

## Что уже есть
- Главная панель менеджера
- Контрагенты и поиск по ИИН/ФИО/телефону
- Быстрая оценка золота и техники
- Залоговые билеты и статусы
- Торги / уведомления / аффинаж
- Касса и закрытие дня
- Архив
- Адаптивная мобильная верстка
- Модальное окно быстрой оценки
- Интерактивные кнопки и уведомления

Это frontend-прототип: данные пока моковые, без backend/API и авторизации.
